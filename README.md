# Velocity Lab Innovation

The public website for Velocity Lab Innovation’s drone-sports systems, Smart Referee service, equipment catalogue, and technical services.

## GitHub Pages

This repository is named `carsonchan3.github.io` so GitHub Pages publishes the static site at:

```text
https://carsonchan3.github.io/
```

Pushes to `main` deploy through GitHub Actions. See [GITHUB_PAGES.md](./GITHUB_PAGES.md) for the deployment workflow, Pages configuration, static-hosting scope, and official GitHub references.

## Important limitation

The GitHub Pages version is a **static preview**. Dynamic catalogue data, enquiry submissions, authentication, the owner dashboard, uploads, and other server-side features remain available on the full VLI application:

```text
https://velolab-gkpolzge.manus.space/
```
