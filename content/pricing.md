# VLI website pricing

Every price shown on velocity-lab.com is set in this file.

**How to edit:** click the pencil icon, change the **Price** column only, then **Commit changes** to `main`. The website updates in about a minute.

- Type prices exactly as they should appear, e.g. `HK$4,329`. Product cards show “From …” using the lowest price of each product.
- Do not change the **ID** column. The other columns are labels to help you find the right row.
- Every product version needs a row here. If a row is missing or an ID is unknown, the update fails and the website keeps the previous prices.
