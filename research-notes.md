# Product Page Reference Notes

## OptiTrack Flex 13 reference review

The current [OptiTrack Flex 13 in-depth page](https://www.optitrack.com/cameras/flex-13) uses a product-led, high-clarity structure. It begins with a restrained split hero containing concise product copy, two calls to action, and a large isolated hardware visual. A compact numerical proof band follows, then alternating explanatory sections pair feature narratives with visual or interactive modules. A small internal page switcher separates in-depth, specifications, and purchase content.

The current [Flex 13 purchase page](https://www.optitrack.com/cameras/flex-13/buy) transitions into a clean two-column commercial layout: product image and alternate visual views on the left, configurable choices and a quote action on the right. Its visual language prioritizes whitespace, an uncluttered product focus, clear option grouping, and persistent commercial calls to action.

Velocity Lab will use this as a high-level reference only. The Product page will be an original dark-charcoal experience built around its own referee-system narrative, with a product hero, capability proof band, system-flow explanation, modular features, and a call to request a tailored demo. It will not reproduce OptiTrack copy, code, branding, assets, or exact layout.

## Use-case context

The [FAI Drone Sports rules summary](https://www.fai.org/page/sporting-rules-0) describes drone soccer as a timed team sport with 3–5 active players, a designated striker, goal rings, and match/referee roles. This supports a use-case narrative focused on configurable role, boundary, and goal-crossing events rather than unsupported performance claims.

The [ABU Robocon contest overview](https://aburobocon2025.mnb.mn/en/contest) describes a robotics competition in which robots complete defined tasks within a set time. This supports positioning VLI as a validation and review layer for competition zones, task sequences, and post-run analysis; it does not imply any affiliation with ABU Robocon.

## Pricing configuration reference

The current [OptiTrack Build My System page](https://www.optitrack.com/systems) uses a configuration-first quote flow: visitors select grouped system variables, see a concise system summary, and use a clear “Get Pricing” action. The related [OptiTrack contact page](https://www.optitrack.com/contact) collects structured project information alongside an open message field so a sales team can scope the request.

The VLI Pricing page will use this pattern only at a high level. It will provide original Class 20, Class 40, and Custom Class system cards, then allow visitors to choose Rental or One-off Purchase. The selected configuration will prefill an original VLI pricing-request modal that reuses the existing enquiry fields and submits through the current contact-request workflow. No OptiTrack copy, assets, code, branding, or exact layout will be reused.
